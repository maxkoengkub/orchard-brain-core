# Orchard Brain Core

An explainable orchard intelligence system for durian cultivation.

## Features

- Orchard Memory
- Knowledge Graph
- Multi-Agent System
- Causal Reasoning Engine
- Scientific Thresholds
- Health Assessment
- Risk Analysis

## Current Modules

- orchard_memory.py
- causal_engine.py
- orchard_graph.py
- water_agent.py
- disease_agent.py
- nutrition_agent.py
- flowering_agent.py
- yield_agent.py
- orchard_orchestrator.py
- orchard_report.py
